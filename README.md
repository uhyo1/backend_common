# backend_common

共通 DTO・ユーティリティをまとめたモジュールです。  
他の Spring Boot サービス（UI / Data / Send / Receive）から参照されます。

---

## 📦 役割

- 共通 DTO（データ転送オブジェクト）
- 共通ユーティリティクラス
- 共通定数
- 他サービス間の依存を減らすための基盤モジュール

---

## 🔗 依存関係

このモジュールは **他のサービスから参照されるだけ** で、  
自身は他サービスに依存しません。

---

## 🚀 ビルド

mvn clean install
これにより、他サービスが利用できる jar がローカルに生成されます。
